# Blockchain Voting Project

This is a simple blockchain-based voting system that demonstrates how blockchain works using JavaScript and basic blockchain concepts. It includes functionality for validating the integrity of the blockchain and adding new votes as blocks.

## Features
- Create and validate a blockchain.
- Add voting data as blocks.
- Check the validity of the entire blockchain.
